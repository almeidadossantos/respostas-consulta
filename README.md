# respostas-consulta-exploratoria
Este repositório disponibiliza os resultados agregados da consulta exploratória utilizada no estudo Desafios Enfrentados por Pesquisadores Iniciantes na Área de Computação.  O arquivo `Respostas_da_consulta_exploratoria.pdf` contém as estatísticas e respostas agregadas exportadas do Google Forms, preservando o anonimato dos participantes.
